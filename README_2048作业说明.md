## 二、作品简介

本作品是“校园成长版 2048”。玩家使用键盘方向键移动数字方块，相同数字碰撞后合并并增加分数。数字方块对应校园成长阶段，例如新生、课程、学分、社团、实践、奖学金、优秀学生、毕业生和校园达人。

作品保留 2048 的核心规则，同时加入了校园主题、成长进度条、成就撒花提示和玩家排行榜。

## 三、运行方法

1. 双击 `index.html`。
2. 在浏览器中输入玩家昵称。
3. 点击“开始游戏”。
4. 使用键盘方向键移动方块。
5. 相同数字会合并，分数会增加。
6. 游戏结束后点击“提交本局分数”保存成绩。

本地直接打开时，即使没有网络，游戏核心功能也可以运行。排行榜未连接在线数据库时，会保存为当前浏览器的本机排行榜。

## 四、主要功能

- 开始游戏和重新开始
- 方向键控制方块
- 相同数字合并和计分
- 每次有效移动后生成新方块
- 撞满且无法继续合并时显示游戏结束
- 达到 2048 时显示胜利提示
- 撤销一步
- 最高分记录
- 蓝色和橙色校园主题配色
- 校园成长阶段名称和进度条
- 成就达成时弹出提示并撒花
- 输入昵称并提交分数
- 显示前十名玩家排行榜
- 支持 Supabase 在线排行榜

## 五、在线排行榜配置

在线排行榜使用 Supabase。数据库中创建了 `public.scores` 表，并配置了查询和提交分数权限。

`index.html` 中的配置位置如下：

```js
const SUPABASE_URL = '你的 Supabase URL';
const SUPABASE_ANON_KEY = '你的 Publishable key 或 anon public key';
```

只应使用公开的 Publishable key 或 anon public key。不要在网页中填写 Secret key、`service_role` key 或数据库密码。

## 七、作品特色

本作品没有改变 2048 的基本玩法，而是用校园成长故事包装数字方块，使每个数字阶段都有明确的主题含义。在线排行榜让不同玩家可以比较分数，成就撒花则增加了游戏反馈和展示效果。
